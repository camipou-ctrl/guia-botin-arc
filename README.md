# Guía de Botín ARC

App web en español para consultar los objetos de ARC Raiders desde el teléfono: qué guardar, reciclar o vender, en qué se usa cada objeto y los mejores lugares de cada mapa para encontrarlo.

Funciona sin conexión después de abrirla una vez y se puede agregar a la pantalla de inicio.

## Fuentes de datos
- Objetos, usos, reciclaje y mejoras: [RaidTheory/arcraiders-data](https://github.com/RaidTheory/arcraiders-data) (versión 1.42 del juego).
- Lugares por mapa y contenedores: [allthings.how](https://allthings.how/arc-raiders/map/), consultado el 21/10/2026.
